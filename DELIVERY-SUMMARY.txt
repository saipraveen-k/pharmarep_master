## ✅ System Components

### Backend (FastAPI)
```python
POST /api/start_query          # Launch search
GET /api/status/{query_id}     # Track progress
GET /api/candidates/{query_id} # Get results
GET /api/report/{query_id}     # Download PDF
POST /api/review/{query_id}    # Flag for review
```

### Workers (Parallel)
- **PapersWorker** → Europe PMC + PubMed
- **TrialsWorker** → ClinicalTrials.gov
- **PatentsWorker** → Patent databases
- **MarketWorker** → Market data

### Orchestrator
1. Master Planner LLM (decompose query)
2. Spawn 4 workers (parallel execution)
3. Aggregator (deterministic scoring)
4. LLM Ranking (re-score top 10)
5. PDF Generation (automatic reports)

### Frontend (Streamlit)
- Query input form
- Real-time progress tracking
- Candidate cards with evidence
- PDF download button
- Flag for review function

### Database (SQLite)
- queries (tracking)
- hits (raw extractions)
- candidates (aggregated results)
- results (final reports)
- human_reviews (flagged items)

## 🧠 How It Works

```
Query: "Alzheimer's disease treatment"
    ↓
Master Planner LLM
├─ Subtask 1: Search papers
├─ Subtask 2: Search trials
├─ Subtask 3: Search patents
└─ Subtask 4: Search market
    ↓
4 Workers (PARALLEL)
├─ PapersWorker: 50 paper abstracts → LLM extract → 20 hits
├─ TrialsWorker: 30 trials → LLM extract → 15 hits
├─ PatentsWorker: 10 patents → LLM extract → 8 hits
└─ MarketWorker: 5 items → LLM extract → 4 hits
    ↓
Aggregator
├─ Group by drug (normalized)
├─ Compute deterministic scores
├─ Apply multi-source bonus
└─ Result: 18 unique candidates
    ↓
LLM Ranking
├─ Re-score top 10
├─ Add justifications
└─ final_score = 0.6*det + 0.4*llm
    ↓
PDF Generator
├─ Top candidates table
├─ Evidence summaries
├─ Methodology section
└─ Professional PDF report
    ↓
Frontend Display
└─ Show candidates, download PDF
```

## 📊 Scoring Formula

```
clinical_component = 0.5 × trial_confidence
paper_component = 0.3 × avg(paper_confidences)
patent_component = 0.1 × max(patent_confidences)
market_component = 0.1 × max(market_confidences)

base_score = sum of components

multisource_bonus = 1.0 + 0.05 × (distinct_sources - 1)

final_score = base_score × multisource_bonus (capped at 1.0)
```

**Example:**
- Donepezil for Alzheimer's
- Sources: trials (positive), papers, patents, market → 4 sources
- Base score: 0.88
- Bonus: 1.0 + 0.05×3 = 1.15
- Final: 0.88 × 1.15 = 1.0 ✨
